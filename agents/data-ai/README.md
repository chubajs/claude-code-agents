## The AI Dream Team Workflow

### Complete ML Pipeline
```
1. data-scientist (analyze data, build initial model)
2. ml-engineer (optimize model, feature engineering)
3. mlops-engineer (setup infrastructure, MLOps)
4. [production deployment]
```

### LLM Application Development
```
1. prompt-engineer (design prompts, optimize)
2. ai-engineer (build RAG, integrate LLMs)
3. mlops-engineer (monitoring, scaling)
```

### Data Pipeline to Insights
```
1. data-engineer (build ETL, data warehouse)
2. data-scientist (analyze, create models)
3. mlops-engineer (productionize)
```

## Use Case Selection

**Building chatbot/LLM app?**
→ prompt-engineer + ai-engineer

**Predictive modeling?**
→ data-scientist + ml-engineer

**Production ML system?**
→ Full stack: data-engineer → ml-engineer → mlops-engineer

**Data analytics platform?**
→ data-engineer + data-scientist

**Model optimization?**
→ prompt-engineer (for LLMs) or ml-engineer (for ML models)

**ML infrastructure?**
→ mlops-engineer + data-engineer
